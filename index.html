02 // 45-DAY CURRICULUM BLUEPRINT

The 9 Condensed Program Phases

45 Days of core intensive learning followed by ~2 months of extended ecosystem engagement, hackathons, and internship pipelines.

PHASE 01 // DAYS 01–10
~15 HOURS LIVE & LABS

Python Foundation

Basics → APIs → Mini chatbot. Master modern Python syntax, data structures, asynchronous event loops, REST endpoints, and build a functioning mini-chatbot.

  • Python syntax, loops, lists, dicts & error handling
  • API integration, requests & JSON parsing
  • Build & deploy a functioning Mini Chatbot
PHASE 02 // DAYS 11–15
~8 HOURS LIVE & LABS

AI Fundamentals & Prompting

AI concepts & Prompt engineering. Understand token probabilities, context windows, few-shot prompts, chain-of-thought, and hallucination reduction.

  • AI, ML, Deep Learning & LLM architectures
  • System prompts, Few-shot & Chain-of-Thought (CoT)
  • Prompt benchmark evaluation test harness
PHASE 03 // DAYS 16–22
~12 HOURS LIVE & LABS

AI Tools Mastery

Text, Image, Audio, Video & Code AI. Master the full creative & technical generative AI toolchains for production workflows.

  • Text AI & Advanced LLM prompting
  • Image & Video AI (Midjourney, Flux, Runway, Kling)
  • Audio (ElevenLabs/Whisper) & Code AI (Cursor/Copilot)
PHASE 04 // DAYS 23–26
~7 HOURS LIVE & LABS

Cybersecurity & Data Protection

AI in security & Data protection. Defend systems from prompt injection, jailbreaks, data leakage, and implement programmatic AI Guardrails.

  • Prompt injection attacks & defense strategies
  • PII protection, data leakage & enterprise governance
  • AI Guardrails (NeMo, Guardrails AI) integration
PHASE 05 // DAYS 27–29
~5 HOURS LIVE & LABS

AI Trends, Careers & Portfolio

AI careers & Portfolio building. Analyze the global AI job market, map emerging roles, and engineer your GitHub portfolio and LinkedIn presence.

  • Mapping high-growth AI roles & market compensation
  • GitHub portfolio architecture & documentation
  • LinkedIn optimization & recruiter outreach strategy
PHASE 06 // DAYS 30–32
~5 HOURS LIVE & LABS

AI in Robotics

AI + robotics basics. Understand sensory perception, computer vision, embodied intelligence, and spatial simulation principles.

  • Embodied AI & Robotics fundamentals
  • Sensors (LiDAR, Cameras) & computer vision
  • Vision-Language-Action (VLA) navigation simulation
PHASE 07 // DAYS 33–40 (CORE OUTCOME)
~14 HOURS LIVE & AGENT BUILDS

AI Agent Development

The core differentiator of AI DISHA. Build the 4 flagship agents: Research Agent, Code Assistant, Automation Agent, and Multi-Tool Agent.

  • 1. Research Agent (Topic Input → Structured Report)
  • 2. Code Assistant (Debug + Generate code)
  • 3. Automation Agent (Multi-step workflows)
  • 4. Multi-Tool Agent (Search + Summarize + Output)
PHASE 08 // DAYS 41–43
~10 HOURS HACKATHON & MENTORSHIP

Demo Projects & Hackathon

Final project delivery + 24–48 Hour Hackathon. Teams of 3–5 compete for ₹15K–20K prize pool and talent identification pipeline.

  • Full-stack final project implementation
